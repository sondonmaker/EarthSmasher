## 호스팅 방법 (택 1)

### GitHub Pages (권장)

1. GitHub 저장소 → **Settings → Pages**
2. Source: `main` / folder: `/Docs` 또는 `docs` 폴더로 HTML 이동
3. URL 예: `https://sondonmaker.github.io/EarthSmasher/privacy-policy.html`

### Google Sites / Notion / 개인 웹

`privacy-policy.html` 내용을 그대로 붙여 넣거나 HTML 파일을 업로드합니다.

## Play Console 데이터 안전성 (Data safety) 요약

현재 Earth Smasher 기준:

- **데이터 수집:** 없음 (서버 업로드 없음)
- **로컬 저장:** 게임 세이브, 볼륨/그래픽 설정
- **제3자 공유:** 없음
- **광고 / 추적:** 없음
- **계정:** 없음

Play Console 설문에서는 “앱이 사용자 데이터를 수집하지 않음” 또는 로컬 저장만 해당하는 항목으로 답변하면 됩니다.
