# 07. 장기 확장 로드맵

펭구·밈코인 게임 생태계의 표준 확장 공식을 따릅니다.

```
[1단계] 싱글 런 데모
    ↓  차트 달리기 + 꼬리 + DOGE/PEPE 보스 + X GIF 홍보
[2단계] 리더보드 & 스킨
    ↓  주간 랭킹 + SNEK 홀더 스킨 + 광고/IAP
[3단계] IO 멀티 (Slither.io)
    ↓  대규모 홀더 유입 + Web3 지갑 연동
[4단계] 캐주얼 격투
    ↓  SNEK IP 멀티 게임 브랜드화
```

---

## 2단계: 랭킹 & 레이스

### 글로벌 리더보드

- 주간 시즌 Top 10 → SNEK 코인 에어드랍 (→ [05-monetization-legal.md](05-monetization-legal.md))
- "오늘의 Top Scorer" 글로벌 점수판 → X 인증샷 유도

### Ghost 레이스 (비동기 멀티)

- Mario Kart 스타일: 다른 플레이어 기록(유령)과 동시에 차트 위 레이스
- 서버에 run replay 저장 → Ghost 데이터로 재생

### 스킨 시스템

- SNEK 홀더 PFP 연동 스킨
- IAP / 이벤트 보상 스킨
- 리더보드 VIP 배지

---

## 3단계: IO 장르 (Slither.io 스타일)

### 컨셉

넓은 3D 필드에서 수십 명의 SNEK이 코인을 먹고 덩치를 키우며, 상대 머리를 자신의 몸통에 부딪히게 해 처치.

### 왜 적합한가

- 밈코인 **"고래 vs 개미"** 생존 경쟁 컨셉과 일치
- NFT / 스킨 과시 환경
- 커뮤니티 대규모 유입

### 기술

| 라이브러리 | 용도 |
|------------|------|
| Photon (PUN / Fusion) | 실시간 멀티 |
| Fish-Net | Unity 네트워킹 대안 |

### Web3 연동 (선택)

- Cardano 지갑 연결
- SNEK 홀더 전용 로비 / 스킨
- 온체인 이벤트 연계

---

## 4단계: 캐주얼 격투 / 파티

### 컨셉

뱀 캐릭터들이 링 위에서 꼬리로 상대를 후려치거나 불장 브레스로 링 밖 Knockout.

### 참고 타이틀

- **Gang Beasts** — physics 기반 예측 불가 연출
- **Brawlhalla** — 캐주얼 대전
- **Smash Bros** — 링 아웃

### 장점

- 복잡한 격투기술 불필요 → 개발 공수↓
- 예측 불가 GIF·짤 → X 바이럴↑
- SNEK IP **멀티 게임 브랜드** 완성

## 우선순위 원칙

1. **1차 데모 완성 → 커뮤니티 반응 확인** (가장 중요)
2. 반응 긍정 → 리더보드 + 수익화
3. MAU 성장 → IO 멀티
4. IP 브랜드 확립 → 격투·파티
