# 01. 프로젝트 개요

## 기본 정보

| 항목 | 내용 |
|------|------|
| 게임명 (가제) | **SNEK: Chart Runner 3D** |

## 핵심 컨셉

> 양봉 차트 위를 구불구불 달리는 SNEK이 되어, 라이벌 밈코인(DOGE, PEPE, SHIB)의 공격을 피하고 차트를 떡상시켜 우주까지 진출하는 게임.

- **10초 만에 규칙 이해** — 펭구 게임처럼 즉각적인 재미
- **밈 문화 + 크립토 요소** — 양봉/음봉, FUD, RUG PULLED, TO THE MOON
- **바이럴 최적화** — X(트위터) 공유용 5~15초 GIF·짤 연출

## SNEK 팀이 환영할 가능성이 높은 이유

1. **내러티브·홀더 유입** — 플레이 가능한 모바일 게임은 신규 유저·바이럴 효과를 크게 만듦
2. **IP 오픈 생태계** — SNEK은 팬·개발자 2차 창작을 권장하는 문화
3. **펭구 전례** — Pudgy Penguins가 커뮤니티 주도 게임으로 대성공한 사례
4. **마케팅 비용 제로** — 팀 입장에서 추가 비용 없이 고품질 홍보 거리 확보

## SNEK 팀 협업 제안 방법

### 제안 시 함께 전달할 것

- 플레이 영상 / GIF / 초기 APK·TestFlight 링크
- 인게임 크레딧: **"SNEK Fan-Made Game"** 명시 + 공식 커뮤니티 링크
- (선택) SNEK 홀더 지갑 연동, 홀더 전용 랭킹전·이벤트
