## 핵심 요약

- **장르**: 3D 하이퍼캐주얼 3인칭 런 (차트 위를 달리는 SNEK)
- **플랫폼**: Android / iOS (PC 데모 우선)
- **엔진**: Unity 3D (URP)
- **1차 목표**: 10일 내 플레이 가능 데모 → SNEK 디스코드/X 공유
- **수익화**: 보상형·전면 광고 + 광고 제거 IAP ($2.99~$4.99)
- **확장**: 리더보드 → Slither.io 스타일 IO → 캐주얼 격투

## 결론: SNEK 팀 반응 전망

SNEK·펭구 같은 밈코인/Web3 커뮤니티는 IP 확장에 적극적입니다.  
완성도 있는 팬메이드 데모 + 공식 홍보 협업 제안 시 **리트윗·커뮤니티 지원 가능성이 높습니다.**
