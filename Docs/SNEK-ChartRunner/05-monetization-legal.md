# 05. 수익화 & 법적 가이드

## 광고 수익화 (BM)

하이퍼캐주얼 + 리더보드 상금 조합에서 가장 안정적인 모델.

### 광고 배치

| 위치 | 유형 | 설명 |
|------|------|------|
| 리더보드 기록 전송 | 보상형 / 전면 | 점수 서버 등록 전 5~15초 광고 (무료 유저) |
| 부활 (Continue) | 보상형 | 죽었을 때 "광고 1번 보고 이어달리기" |
| 점수 2배 | 보상형 | 게임 종료 후 "광고 보면 점수 2배" |

> 무작정 강제 광고는 이탈률 상승. **보상형 중심** + 전면은 리더보드 등록 시점만.

### 광고 제거 IAP

| 항목 | 내용 |
|------|------|
| 상품명 | SNEK VIP Pass / Remove Ads (No Rugs) |
| 가격 | **$2.99 ~ $4.99** (약 3,900~5,900원) |
| 유형 | Non-Consumable (1회 구매) |
| 혜택 | 모든 강제/전면 광고 스킵 |
| 보너스 (선택) | 황금 SNEK 스킨, 리더보드 VIP 배지 |

**앱스토어 필수**: 광고 제거 버튼 옆 **"구매 복원 (Restore Purchase)"** 버튼 배치.

### Unity SDK

- **Unity Ads** 또는 **Google AdMob** — 전면·보상형
- **Unity IAP** — 광고 제거 Non-Consumable 등록

## 주간 리더보드 상금 (SNEK 코인)

### 법적 리스크: 낮음 (조건부)

도박 성립 3요소 `[대가 + 운 + 상품]` 중 **하나라도 제거**하면 도박 아님.

| 요소 | 대응 |
|------|------|
| 대가 (Consideration) | **완전 무료** — 참가비·SNEK 코인 지불 금지 |
| 운 (Chance) | **실력 기반** — 컨트롤·점수, 랜덤 뽑기 아님 |
| 상품 (Prize) | 에어드랍 방식 지급 (앱 내 직접 송금 X) |

### 앱스토어 정책

- Apple / Google: 앱 내부에서 **암호화폐 직접 상금 지급 금지**
- **권장 방식**: 시즌 종료 후 디스코드/웹에서 지갑 주소 수집 → **에어드랍(Airdrop)**

### 운영 방식

1. 주간 시즌 (월~일)
2. Top 10 지갑 주소 Discord/X DM 수집
3. 공식 또는 운영 지갑에서 SNEK 에어드랍
4. ToS에 명시:
   > "본 이벤트는 순수 재미를 위한 팬메이드 이벤트이며, 매크로·부정행위 적발 시 무통보 자격 박탈"

### 어뷰징 대응

- X / Discord 계정 연동 필수
- 서버 플레이 타임·점수 검증 (→ [06-anti-cheat.md](06-anti-cheat.md))
- IL2CPP 빌드 + 코드 난독화
