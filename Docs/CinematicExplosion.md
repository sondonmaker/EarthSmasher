# 시네마틱 충돌 폭발은 어떻게 만드나?

참고 영상(큰 운석 → 지구 충돌 → 화염 폭발)은 **한 장의 이미지가 아니라 여러 레이어를 겹친 것**입니다.

## 레이어 구성

```
1) 대형 운석 메시/구체     → 멀리서 다가옴
2) 화염 트레일             → 꼬리
3) 충돌 순간
   ├─ 강한 Point Light     → 하얀/주황 섬광
   ├─ 커지는 화구 구(들)   → 폭발 볼륨감
   ├─ 암석 파편 Rigidbody  → 쪼개져 날아감
   ├─ 작은 불씨(embers)    → 스파크
   ├─ 연기 구              → 잔해 연기
   ├─ 충격파 링            → 퍼지는 원
   └─ Camera Shake         → 타격감
4) (선택) Bloom 후처리     → 영상처럼 빛번짐
5) (선택) 사운드           → 저음 충격
```

이미지만 붙인다고 안 나오고, **파티클 + 빛 + 물리 파편 + 카메라**가 핵심입니다.

## 이 프로젝트에서 조작

| 입력 | 동작 |
|------|------|
| 지구 **좌클릭** | 작은 운석 |
| **Space** 또는 **우클릭** | **대형 운석** + 시네마틱 폭발 |

관련 스크립트:
- `BigMeteorStrike.cs` — 큰 운석 접근
- `CinematicExplosion.cs` — 폭발 레이어
- `CameraShake.cs` — 화면 흔들림

## 더 영상처럼 만드는 다음 단계

1. **Window → Rendering → Lighting** 또는 URP면 Volume에 **Bloom** 켜기  
2. Asset Store / 무료 VFX의 fire·smoke 스프라이트를 Particle System에 넣기  
3. 운석을 Sphere 대신 암석 FBX로 교체  
4. 폭발음 AudioSource  
5. 지구 fracture 메시 스왑 (진짜 금 가며 쪼개짐)
